# YeruVerse

> ⚠️ **Этот проект полностью написан ИИ.** Весь код, документация и
> конфигурация созданы с помощью Claude (Anthropic) без ручного написания
> кода человеком. Используйте на свой страх и риск, проверяйте перед
> продакшн-использованием.

Приватная видеосвязь для небольшой компании: экран, голос и клавиатура
передаются напрямую между участниками (WebRTC, peer-to-peer). Сервер
YeruVerse — это только «список комнат»: он раздаёт участников друг другу и
передаёт сигналинг, но видео, аудио и файлы через него не идут.

Работает как веб-страница и как десктопное/мобильное приложение (Tauri).

## Возможности

- Демонстрация экрана нескольких участников одновременно, с раскладкой сцены.
- Звук компьютера идёт вместе с экраном — включая macOS, где браузерные
  движки его не отдают и его снимает само приложение.
- Голосовой чат с шумоподавлением (RNNoise и DeepFilterNet прямо в браузере).
- Чужая трансляция или камера — в отдельном окошке поверх всех программ
  (картинка в картинке): смотреть чужой экран можно, не выходя из своей игры.
- Общий доступ к клавиатуре/мыши для удалённого управления. Замок открывает
  хозяин компьютера поимённо, а управление берёт зритель — и оно запирается
  само, стоит ему свернуть окно.
- Текстовый чат и передача файлов.
- Комнаты по ссылке/коду, без регистрации.
- TURN через Cloudflare — работает и за симметричным NAT (мобильные сети,
  корпоративные фаерволы).
- Автообновление десктопного приложения (Tauri updater).
- Приложение под Windows/macOS/Linux и Android (сборка через Tauri). Linux —
  только Wayland; для Arch и CachyOS есть свой пакет — см. раздел «Linux».

## Быстрый старт (сервер)

```bash
cargo run --release
```

Сервер поднимется на `:8080` и отдаёт веб-версию из `web/`.

## Развёртывание на своём сервере

```bash
cp .env.example .env && $EDITOR .env   # домен и ключи TURN (Cloudflare)
docker compose up -d
```

Compose поднимает сам сервер комнат и Caddy, который сам получает и продлевает
HTTPS-сертификат (Let's Encrypt) и проксирует WebSocket без дополнительной
настройки.

TURN берётся у Cloudflare:
сервер сам выпускает короткоживущие учётки, постоянный ключ в браузер не
попадает. Без TURN соединятся не все — только участники за обычным NAT.

## Десктоп и мобильное приложение

Собирается через [Tauri](https://tauri.app/) из `desktop/`.

```bash
make app          # установщик под текущую систему (.dmg/.msi/.AppImage)
make app-debug    # запуск без упаковки, для разработки
make android      # APK под arm64 (нужны ANDROID_HOME и NDK_HOME)
```

### Linux, в том числе CachyOS

**Только Wayland.** X11 из приложения убран целиком: у enigo выключен backend
`x11rb`, плагин системных сочетаний (он держался на `XGrabKey`) снят с Linux
вместе с ним, а сама сборка при запуске выставляет `GDK_BACKEND=wayland`. В
сеансе X11 приложение не запустится и скажет об этом прямо, а не отвалится
непонятной ошибкой GTK. На CachyOS делать ничего не нужно: Plasma там по
умолчанию и так Wayland.

Tauri на Linux не везёт с собой ни вебвью, ни оболочку окна — он берёт их
у системы:

```bash
make linux-deps    # поставить недостающее
make linux-check   # только сказать, чего не хватает, ничего не ставя
```

Дистрибутив узнаётся по менеджеру пакетов: pacman, apt, dnf, zypper, apk,
xbps, eopkg. Но имена пакетов — только подсказка, а истина везде одна и та же:
модули pkg-config, которые должна отдавать система.

| модуль pkg-config | зачем |
|---|---|
| `webkit2gtk-4.1`, `gtk+-3.0` | окно и вебвью |
| `librsvg-2.0` | значки |
| `ayatana-appindicator3-0.1` (или наследный `appindicator3-0.1`) | значок в лотке |
| `libpulse-simple` | звук компьютера в трансляции |
| `wayland-client`, `xkbcommon` | ввод |

Плюс `cc` и `pkg-config`, а для AppImage ещё `patchelf` и `file`. Пакетов X11
в списке нет и быть не должно; если что-то из них окажется в системе, то
прицепом к `gtk3`, собранному с обоими backend'ами, — нашего кода это не
касается.

Если менеджер незнакомый — NixOS, Gentoo, что-нибудь совсем своё, —
`make linux-check` всё равно назовёт недостающее теми именами, которые понимает
любой дистрибутив, и по ним пакеты находятся поиском. Проверяет он и после
установки, тем же способом: менеджер пакетов бывает доволен и тогда, когда
поставил не то.

Дальше есть два пути:

```bash
make arch         # обычный пакет: ставится и удаляется через pacman
make app          # AppImage — один файл, работает на любом дистрибутиве
```

На Arch лучше первый: AppImage тоже запустится, но живёт сам по себе —
его не видит меню приложений и не удаляет пакетный менеджер. Автообновление
на Linux работает только у AppImage: `.deb` и `.rpm` ставит пакетный
менеджер, и лезть в его хозяйство мимо него нельзя.

**Что работает и чего нет.** Приложение говорит об этом само — недоступные
кнопки просто не появляются, — но знать заранее полезно:

| | Plasma / GNOME | Sway, Hyprland |
|---|---|---|
| Комната, голос, чат, файлы | да | да |
| Трансляция экрана и камеры | да (портал) | да (портал) |
| Звук компьютера в трансляции | да | да |
| Управление чужим компьютером | через портал | протоколами wlroots |
| Системные сочетания клавиш | **нет** | **нет** |
| Курсоры зрителей поверх экрана | **нет** | **нет** |

*Управление* идёт двумя дорогами, и выбирает между ними enigo сам: сперва
портал рабочего стола (`RemoteDesktop` → `ConnectToEIS`, он же libei) — так
устроены GNOME 46+ и Plasma 6.1+, композитор спросит разрешение, как на
демонстрацию экрана; если портала нет — напрямую протоколами wlroots
(`virtual_pointer`, `virtual_keyboard`), которые есть у Sway и Hyprland, но
не у KWin и Mutter. Обе дороги у enigo помечены **экспериментальными**, и это
не формальность: под Wayland это самая молодая часть всей затеи.

*Системных сочетаний* на Linux нет. Забрать клавишу у всей системы под Wayland
нельзя в принципе — клавиатуру раздаёт композитор, — а просят его об этом
порталом `org.freedesktop.portal.GlobalShortcuts`, к которому у нас пока нет
дороги. Прежний путь через `XGrabKey` ушёл вместе с X11. Внутристраничные
сочетания, пока окно в фокусе, работают как везде.

*Курсоров зрителей поверх чужого экрана* на Linux тоже нет. Окно поверх всех
прочих под Wayland ставит композитор, и `always_on_top` у Tauri оборачивается
тихой пустышкой ([tao#1134](https://github.com/tauri-apps/tao/issues/1134),
[tauri#3117](https://github.com/tauri-apps/tauri/issues/3117)). Правильный
протокол для такого окна — `wlr-layer-shell`, но включают его до того, как
окно создано, а такого крючка Tauri не даёт
([tao#925](https://github.com/tauri-apps/tao/issues/925),
[tauri#14277](https://github.com/tauri-apps/tauri/issues/14277) — оба открыты).

*Звук компьютера* снимается с монитора устройства вывода, а это готовая смесь
всего, что звучит, — включая голоса собеседников из самого YeruVerse. Выкинуть
из неё себя нечем ни в PipeWire, ни в PulseAudio (на macOS для этого есть
`excludesCurrentProcessAudio`, на Linux такого рычага нет). Собеседники будут
слышать себя с задержкой; приложение предупреждает об этом при включении
трансляции. Нужен `pipewire-pulse` — на CachyOS он стоит по умолчанию.

### Подпись под macOS

`make app` заводит сертификат сам (`~/.yeruverse/macos.p12`), но **сохраните
его**: macOS помнит выданные приложению разрешения — микрофон, запись экрана,
управление компьютером — не по имени и не по пути, а по подписи. Подпишете
следующую версию другим сертификатом — все разрешения придётся выдавать
заново. Ровно это и происходило, пока подписи не было вовсе.

Для сборки в CI положите его в секреты репозитория; готовые значения печатает

```bash
make mac-cert     # MAC_CERTIFICATE и MAC_CERTIFICATE_PASSWORD
```

Сертификат самоподписанный, аккаунт Apple для этого не нужен. Gatekeeper он не
успокаивает: при первой установке система по-прежнему скажет «не удалось
проверить разработчика», и приложение придётся открыть через правую кнопку →
«Открыть». Чтобы убрать и это, нужен платный Developer ID и нотаризация —
тогда в `build_app.sh` подставляются `APPLE_*` вместо `MAC_CERTIFICATE`.

## Полезные команды

```bash
make help    # список всех команд с описанием
make docker  # собрать образ сервера
make check   # форматирование, clippy, тесты, проверка фронтенда
make browser # прогон комнаты в настоящем браузере (нужен playwright)
```

## Структура проекта

```
src/            сервер комнат (Rust, axum): сигналинг, TURN-креды, обновления
web/            веб-клиент (без сборки, чистый JS): экран, голос, чат, раскладка
desktop/        обёртка Tauri для десктопа и Android
scripts/        сборка, иконки, шумодав, релиз, подписи, проверки
tests/          интеграционные тесты сервера
```
