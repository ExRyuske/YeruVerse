# YeruVerse

[![Сборка](https://github.com/ExRyuske/YeruVerse/actions/workflows/ci.yml/badge.svg)](https://github.com/ExRyuske/YeruVerse/actions/workflows/ci.yml)
[![Релизы](https://img.shields.io/github/v/release/ExRyuske/YeruVerse?display_name=tag)](https://github.com/ExRyuske/YeruVerse/releases)

Комната, в которой показывают свой экран, разговаривают и при желании пускают
друг друга за компьютер. Браузер, приложение для Windows, macOS и Linux,
Android — фронтенд у всех один, приложение только добавляет возможности:
системные сочетания, курсоры поверх окон, приём чужого ввода, мост к Sunshine.

> Ранняя версия. Не открывайте комнату и доступ к компьютеру тем, кому не
> доверяете.

**Через сервер не идёт ничего тяжёлого.** Он сводит участников по WebRTC и
передаёт чат; видео, звук, файлы, курсоры и чужой ввод идут напрямую между
зрителями. Состояние комнат живёт в памяти: ни базы, ни истории, ни учётных
записей, ни cookie.

## Что в комнате

* **Экран и камера** — независимо, в том числе оба сразу. Демонстраций может
  идти несколько, у каждой своя запоминаемая громкость. Камеры видны всегда,
  плитками в углу сцены; плитка разворачивается щелчком.
* **Голос** — полная сетка WebRTC, подавление шума RNNoise, своя громкость
  каждому.
* **Чат** — картинка вставляется по Ctrl+V, файл бросается мышью в любое место
  комнаты. Через сервер идёт только карточка, байты качаются роем.
* **Указки** — курсоры участников поверх видео, у каждого ник и свой цвет.
* **Управление чужим компьютером** — по WebRTC прямо из браузера или через
  Sunshine с Moonlight, когда нужна игра.
* **Горячие клавиши** — микрофон, заглушение всех, «молчать, пока зажато»,
  перехват управления. По умолчанию не занято ничего; в приложении сочетания
  регистрируются системно и работают из полноэкранной игры.

Любую трансляцию можно выключить у себя значком в списке участников. Для чужой
это не «спрятать»: просьба уходит владельцу, и он снимает дорожку именно с
вашего соединения — экономится и канал, и процессор.

**Своя трансляция на сцену не попадает**: свой экран и так перед глазами.
Курсоры зрителей при этом рисует прозрачное окно поверх всех приложений.

## Приватность

У комнаты один секрет — её **код** (100 бит из криптографического источника).
Он же её адрес: комната не «закрывается» вторым паролем, она просто не
находится, пока код неизвестен. В ссылке он живёт во фрагменте (`#код`) — тот
не уходит в строке запроса и не оседает в логах прокси; в журнал сервера
попадает только необратимый отпечаток.

| Что | Как защищено |
|---|---|
| Видео, звук, файлы, курсоры, чужой ввод | DTLS-SRTP напрямую между зрителями — сервер их не видит |
| Чат, сигналинг | TLS до сервера; сам сервер видит их открытыми |

Файлы из чата не ложатся на диск сами — только по нажатию «Сохранить». Политика
содержимого строгая (`script-src 'self'`), встраивание в чужую страницу
запрещено. Чужой ввод принимается только от того, кому вы сами открыли замок.

Комнату можно **сохранить** закладкой в шапке — список личный и лежит в
настройках браузера; на сервере комнат не существует, пока в них никто не сидит.

## Управление чужим компьютером

Пускать за свой компьютер решает хозяин, **поимённо**: в списке участников
рядом с каждым есть замок. Пока он закрыт, человек не знает даже адреса
Sunshine. Разрешение снимается тем же нажатием и не переживает выход из комнаты.

Простой путь — наш, по WebRTC: зритель тыкает прямо в демонстрацию экрана.
Хватает, чтобы нажать кнопку в чужом окне или напечатать строку; принимает ввод
только настольное приложение.

Для игр — **Sunshine** (или форк Apollo) с **Moonlight**: захват полноэкранного
режима, виртуальный геймпад, задержка в единицы миллисекунд. Нажатие 🎮 у
зрителя запускает Moonlight и само проводит сопряжение. Из локальной сети всё
работает сразу; снаружи нужно пробросить на роутере **TCP 47984–47990** и
**UDP 47998–48010** — либо соединить машины через Tailscale или ZeroTier.

Полноэкранную игру браузер не захватывает: ей достаётся чёрный кадр.
Приложение это замечает и просит перевести игру в режим «окно без рамок» и
выключить HDR. Не хочется — Sunshine.

## Запуск

```bash
cargo run                       # http://localhost:8080
PORT=3000 cargo run --release   # или: make server
```

| Переменная | Зачем |
|---|---|
| `PORT` | порт HTTP (по умолчанию 8080) |
| `WEB_DIR` | каталог со статикой (по умолчанию `web`) |
| `CF_TURN_KEY_ID`, `CF_TURN_API_TOKEN` | TURN у Cloudflare (рекомендуется) |
| `TURN_URL`, `TURN_USER`, `TURN_PASS` | TURN у любого другого провайдера |
| `TURN_TTL` | срок жизни выданных учёток, секунд |

Двух вкладок на `http://localhost:8080/#test` хватает, чтобы увидеть комнату
изнутри. Между устройствами нужен **HTTPS**: микрофон и захват экрана браузеры
отдают только в защищённом контексте. По той же причине окно приложения грузится
прямо с сервера, а не из локальных файлов, — и заодно обновляется вместе с ним.
Свой домен нужно добавить в `desktop/src-tauri/capabilities/default.json`.

```bash
cargo install tauri-cli --version '^2' --locked
make app            # .dmg / .msi / .AppImage под текущую систему
make android        # APK под arm64, сразу подписанный
```

**APK обязательно подписывать** — неподписанный телефон не примет. Ключ
создаётся при первом запуске в `~/.yeruverse/android.jks`; **сохраните его**:
обновление поверх установленного принимается только от того же ключа.
Проект Android генерируется, поэтому правки в нём накатывает
`scripts/android_patch.py` — из `make android` он вызывается сам.

## Выпуск версии

**`git push` в `main` — и всё.** Workflow поднимает patch-версию в обоих
пакетах и обоих lockfile, коммитит, ставит тег, собирает образ, установщики и
APK и **публикует** релиз со списком изменений. Приложение раз в шесть часов
сверяется с `releases/latest/download/latest.json` и проверяет подпись пакета
встроенным ключом — без верной подписи установка не начнётся.

Руками — только два случая: **minor или major** (Actions → сборка → Run
workflow) и **не выпускать этот push** (`[skip release]` в сообщении коммита).

Права нужны такие: Settings → Actions → General → Workflow permissions →
`contents: write`. Секреты — Settings → Secrets and variables → Actions, **до**
первого push, иначе установщики соберутся без подписи:

| Секрет | Где взять |
|---|---|
| `TAURI_SIGNING_PRIVATE_KEY` | `make updater-key`, затем **всё содержимое** `~/.yeruverse/updater.key` |
| `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` | содержимое `~/.yeruverse/updater.key.password` |
| `ANDROID_KEYSTORE` | `base64 -i ~/.yeruverse/android.jks` |
| `ANDROID_KEYSTORE_PASS` | содержимое `~/.yeruverse/android.jks.password` |

Ключ подписи — одна длинная строка base64, начинается с
`dW50cnVzdGVkIGNvbW1lbnQ6`. Копировать целиком, не путать с `updater.key.pub`:
иначе сборка падает с невразумительным `Missing comment in secret key`.

## Развёртывание

```bash
cp .env.example .env && $EDITOR .env    # домен и ключи TURN
docker compose up -d                    # готовый образ из ghcr.io
```

Поднимаются сервер комнат и **Caddy** — HTTPS с автопродлением и проксирование
WebSocket. Домен из `.env` должен указывать A-записью на сервер. Пакеты в GitHub
по умолчанию приватные, и `docker compose up` отвечает `unauthorized`: откройте
доступ (Packages → yeruverse → Package settings → Change visibility) или
собирайте на месте.

**TURN** нужен там, где прямое соединение не выходит, — мобильные операторы и
корпоративные сети раздают симметричный NAT. Держать свой coturn не нужно:
Cloudflare (Realtime → TURN → создать ключ) отдаёт `CF_TURN_KEY_ID` и
`CF_TURN_API_TOKEN`, а сервер сам выпускает короткоживущие учётки. Проверка —
`curl -s https://ваш-домен/config.json`, должно быть `"turn": true`.

## Структура

```
src/                 сервер: WebSocket, комнаты в памяти, выдача ICE
web/js/app.js        склейка: сеть, сцена, трансляции
web/js/mesh.js       полносвязная WebRTC-сеть (perfect negotiation)
web/js/voice.js      микрофон, приём, индикаторы речи
web/js/swarm.js      рой: файлы кусками по 64 КБ
web/js/*.js          чат, курсоры, ввод, настройки, горячие клавиши, мост
desktop/src-tauri/   оболочка Tauri: ввод, сочетания, оверлей, мост к Sunshine
scripts/             иконки, правки Android-проекта, сборка, подпись, выпуск
```
